# 구현 계획

**목표** 호가창 데이터를 깊이·정밀도·시간 해상도 축으로 줄였을 때 저장 용량이 얼마나 줄고 딥러닝 예측 정확도가 얼마나 떨어지는지 재서, 용량과 정확도의 파레토 경계를 밝힌다.

**연구 질문**
- Q1. 축소에 따라 저장 용량이 얼마나 줄어드는가
- Q2. 같은 축소가 DeepLOB 계열 모델의 예측 정확도를 얼마나 떨어뜨리는가
- Q3. 어떤 축소는 거의 손해가 없고 어떤 축소는 치명적인가

**일정**

| 기간 | 할 일 | 완료 조건 |
|---|---|---|
| 9월 | 수집기 완성, 장기 수집 시작. 병행: GPU 환경, DeepLOB FI-2010 재현 | 72시간 무중단, FI-2010 정확도 재현 |
| 10월 | 호가창 복원기, 축소 변환기, 라벨링·학습 파이프라인 | 전체 깊이 vs 10레벨 첫 결과 |
| 11월 | 실험 행렬 전체 실행 | 파레토 그림 |
| 12월 | 집필, 투고 | 국내 저널 투고 |

주 10~15시간. 서버 운영은 주 2~3시간 이내. 매주 일요일 갱신.

**보류(전역 후)** Tickfold 인코더, 베이스라인 비교, 조회 벤치마크.

- [ ] 24시간 강제 종료 대비 겹치기 재연결
- [ ] Docker + systemd 자동 재시작, chrony 시각 동기화

메모
- 호가 메시지는 바뀐 가격 레벨의 새 합계 수량만 온다. 증분이 아니라 절대값이고, 0은 레벨 삭제다.
- 메시지의 `U`는 첫 순번, `u`는 마지막 순번. 새 메시지의 `U`가 직전 `u + 1`이 아니면 갭, `u`가 직전 `u` 이하면 중복.
- 수집은 9~10월은 BTCUSDT 한 종목. 첫 결과 후 8~10종목으로 확대, 모델 학습은 유동성 높은 3~5종목만.

- [ ] 가격 정밀도: 호가 단위를 더 거칠게
